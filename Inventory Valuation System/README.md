# Inventory Valuation System
### Designed and implemented a custom Inventory Valuation module in Odoo 12 to calculate real-time inventory valuation, stock movement analysis, and Cost of Goods Sold (COGS). The solution leverages stock.move and stock.quant data structures to provide accurate inventory cost visibility and financial reporting support.
