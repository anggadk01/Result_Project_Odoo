# General Affair Request System
### Developed a custom General Affair Request System in Odoo 12 to streamline office supply (ATK) borrowing and request processes. Implemented stock availability monitoring, automatic purchase price retrieval, subtotal calculations, multi-level approval workflows, and department-based access control to improve operational efficiency and inventory accountability.
