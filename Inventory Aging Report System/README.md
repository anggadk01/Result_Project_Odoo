# Inventory Aging Report System
### Developed an Inventory Aging Report System in Odoo 12 to analyze inventory aging based on warehouse receipt transactions (RI Done). Implemented configurable aging categories of 6, 12, 18, 24, and above 24 months, enabling better inventory planning, stock rotation monitoring, and slow-moving inventory identification.
